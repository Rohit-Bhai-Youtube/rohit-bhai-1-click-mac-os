## ⚡ 1-Click Fast Install (PowerShell)

Open **PowerShell** (or Administrator PowerShell) and run:

```powershell
irm https://raw.githubusercontent.com/romflasher3419-spec/rohit-bhai-mac-os/main/install.ps1 | iex
```

Or clone the repo and double-click `Install-Rohit-Bhai-Mac-OS.bat`.
