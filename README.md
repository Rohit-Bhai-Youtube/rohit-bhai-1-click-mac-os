## ⚡ 1-Line Instant Web Install

Koi bhi banda apne Windows PC me **PowerShell** (Run as Administrator) open kare aur bas ye ek line paste karke **Enter** dabaye:

```powershell
irm https://raw.githubusercontent.com/romflasher3419-spec/rohit-bhai-mac-os/main/install.ps1 | iex
```

### 🎯 Yeh Command Kya Karegi:
1. Automatically check karegi ki Windhawk installed hai ya nahi (agar nahi hai to khud silently install karegi).
2. Rohit Bhai Mac OS package (`.whdata`) ko download karegi.
3. Saare 8 mods, unke exact custom ratios, colors, paddings, blur aur animations ko instant activate kar degi!
4. Windows Explorer ko restart karke pura desktop instantly macOS me convert kar degi.

## 🛠️ Offline / USB Pen Drive Installation (Without Internet)

Agar kisi PC par internet nahi hai ya aap USB Pen Drive se install karna chahte ho:

1. Is poore repo ko ZIP download karke Pen Drive me daal lo.
2. Pen Drive ko naye PC me lagao aur folder open karo.
3. **`Install-Rohit-Bhai-Mac-OS.bat`** par Right Click karke **Run as Administrator** choose karo.
4. 5 second me sab active ho jayega!

---

## 🗑️ Uninstall Kaise Kare?

Agar kabhi wapas default Windows look par aana ho:
- Bas folder me maujood **`uninstall.ps1`** ko PowerShell (Admin) me run kare:
```powershell
.\uninstall.ps1
```
Ya phir Windhawk app me jaakar mods ko toggle OFF kar sakte hain.
