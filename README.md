## 🛠️ Offline / USB Pen Drive Installation

1. Download or clone this repository to a USB drive.
2. Run [`Install-Rohit-Bhai-Mac-OS.bat`](Install-Rohit-Bhai-Mac-OS.bat) as Administrator.
3. Everything installs offline within 10 seconds!
